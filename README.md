# Даалгаврын Тракер (Assignment Tracker)

## Алсын хараа
Оюутнуудад хичээлийн даалгавар, дуусах хугацааг нэг дороос хянаж, зохион байгуулахад тусалдаг энгийн веб апп. Даалгавар алдах, хугацаа даваарлахаас урьдчилан сэргийлж, суралцах төлөвлөгөөг сайжруулна.

## Хэрэглэгчийн дүрүүд (Personas)

### 1. Бүтэн цагийн бакалаврын оюутан
Улиралд 5-6 хичээл судалдаг 3-р курсын оюутан, олон платформ (GitLab, Teams, цаасан хуваарь) дээрх даалгаврын хугацааг хянахад бэрхшээлтэй. Бүх даалгаврыг нэг дэлгэц дээр, аль нь хэзээ дуусахыг, дүнд хэдэн хувийн жин эзэлж байгааг харах хүсэлтэй.

### 2. Хагас цагаар ажилладаг оюутан
Хагас цагаар ажилладаг тул сурах цаг хязгаарлагдмал оюутан. Даалгавраа хугацаа, хүндрэлээр нь эрэмбэлж, ажлын ээлж хоорондоо юу ч алдахгүй байхын тулд сануулга авах хүсэлтэй.

### 3. Багшийн туслах / Хичээл зохицуулагч
Хичээлийн даалгаврын хуваарийг удирдахад тусалдаг бөгөөд "энэ хэзээ дуусах вэ?" гэсэн асуултын тоог багасгахын тулд дуусах хугацааг оюутны тракер руу автоматаар нийлүүлж, нийтлэх хүсэлтэй.

## Хэрэглэгчийн замнал (User Journeys)

### Замнал 1: Шинэ даалгавар нэмж, хянах
Оюутан нэвтэрч, гарчиг, хичээл, дуусах хугацаа, тооцоолсон цагийг агуулсан шинэ даалгавар үүсгэнэ. Систем үүнийг яаралтай байдлаар нь эрэмбэлж dashboard дээр харуулна. Хугацаа ойртохын хирээр оюутан өнгөөр ялгасан анхааруулга хүлээн авч, "хийгдэж байгаа" эсвэл "дууссан" гэж тэмдэглэж болно.

### Замнал 2: Долоо хоногийн төлөвлөлтийн харагдац
Оюутан "Энэ долоо хоног" харагдацыг нээж, дараагийн 7 хоногт дуусах бүх хичээлийн даалгаврыг чухлын дарааллаар харна. Хувийн чухлыг үндэслэн даалгавраа дахин эрэмбэлж, дууссан зүйлээ тэмдэглэж, долоо хоногийн ажлын ачааллаа тодорхой харах боломжтой болно.

## Архитектурын анхны эскиз
+-------------------+ +--------------------+ +------------------+
| Веб хөтөч | <---> | Spring Boot API | <---> | Мэдээллийн сан |
| (Frontend UI) | | (REST Endpoints) | | (H2/PostgreSQL)|
+-------------------+ +--------------------+ +------------------+
| |
| v
| +------------------+
+-----------------> | Нэвтрэлт / |
| Хэрэглэгчийн үйлч|
+------------------+

- **Frontend**: Даалгавраа харах, удирдах энгийн веб UI (HTML/JS эсвэл React).
- **Backend**: Даалгавар, хичээлийн CRUD үйлдлүүдийг гүйцэтгэдэг Spring Boot REST API.
- **Database**: Даалгавар, хичээл, дуусах хугацаа, хэрэглэгчийн мэдээллийг хадгалдаг сан.
